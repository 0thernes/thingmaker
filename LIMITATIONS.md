# Limitations & Scope Boundaries (`LIMITATIONS.md`)

1. **Procedural Fiction Only (Real vs. Metaphor):** All creatures, artifacts, taxonomies, field notes, dates, and lore generated by THINGMAKER are deterministic combinatorial fiction driven by `xmur3`/`mulberry32` PRNG streams and curated word/template pools. They are not scientific classifications, biological simulations, or factual claims.
2. **Browser Storage Scope:** History (`RECENTLY MADE`) and pinned shelf items rely on `localStorage`; clearing browser storage or running in ephemeral private windows resets saved items.
3. **Export Fidelity:** PNG card export renders SVG via browser `<canvas>` and depends on standard browser SVG/Canvas support; headless `selftest.mjs` validates DOM/SVG structure and generator determinism in `node:vm` without rendering raster pixels.
4. **No External Fonts or Telemetry:** Zero external network calls are made at runtime; visual typography uses system font stacks, which vary slightly across operating systems.
